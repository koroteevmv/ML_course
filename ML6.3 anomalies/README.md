#### Методические указания

##### Что такое аномалии и зачем их искать

**Аномалия** (выброс, outlier) — это наблюдение, которое существенно отличается от остальных наблюдений в выборке. Аномалии могут возникать по разным причинам: ошибки измерений, ошибки ввода данных, мошеннические операции, редкие события, сбои оборудования и т.д.

Выделяют несколько типов аномалий:

- **Точечные аномалии** — отдельное наблюдение, сильно отличающееся от остальных. Например, один клиент с нехарактерно большой суммой покупки.
- **Контекстные (условные) аномалии** — наблюдение, которое является аномальным только в определённом контексте. Например, температура +30°C летом — норма, а зимой — аномалия.
- **Коллективные аномалии** — группа наблюдений, которая вместе выглядит аномально, хотя каждое из них по отдельности может не быть аномалией. Например, серия последовательных мошеннических транзакций.

Основные подходы к обнаружению аномалий:

1. **Статистические методы** — предполагают, что «нормальные» данные подчиняются некоторому распределению, и ищут наблюдения, которые плохо согласуются с этим распределением (z-score, IQR, расстояние Махаланобиса).
2. **Методы на основе близости и плотности** — ищут наблюдения, которые находятся далеко от других наблюдений или в областях с низкой плотностью (LOF, DBSCAN).
3. **Методы на основе изоляции** — используют предположение, что аномалии легче «изолировать» от остальных данных (Isolation Forest).
4. **Методы одноклассовой классификации** — строят модель только на «нормальных» данных и затем определяют, насколько новое наблюдение похоже на нормальное (One-Class SVM, EllipticEnvelope).

Важно понимать, что в задачах обнаружения аномалий, как правило, **нет размеченных данных** (или аномалий очень мало), поэтому это задача обучения без учителя. Однако для оценки качества методов на синтетических данных мы можем знать истинные метки аномалий и использовать стандартные метрики классификации.

Для дальнейшей работы нам понадобится вспомогательная функция оценки качества. В задачах обнаружения аномалий аномалии считаются «положительным» классом (1), а норма — «отрицательным» (0). Тогда:

- **Precision** — доля истинных аномалий среди всех, кого метод назвал аномалиями.
- **Recall** — доля найденных аномалий среди всех истинных аномалий.
- **F1** — гармоническое среднее precision и recall.
- **ROC-AUC** — площадь под ROC-кривой (работает с непрерывными оценками аномальности).
- **Average Precision** — площадь под PR-кривой (устойчивее при сильном дисбалансе).

```python
def evaluate_detector(y_true, y_pred, scores=None):
    """
    Оценивает качество детектора аномалий.
    
    Параметры:
        y_true: истинные метки (0 — норма, 1 — аномалия)
        y_pred: предсказанные метки (0 — норма, 1 — аномалия)
        scores: непрерывные оценки аномальности (чем больше, тем аномальнее)
    """
    metrics = {
        'Precision': precision_score(y_true, y_pred, zero_division=0),
        'Recall': recall_score(y_true, y_pred),
        'F1': f1_score(y_true, y_pred),
    }
    if scores is not None:
        metrics['ROC-AUC'] = roc_auc_score(y_true, scores)
        metrics['Avg Precision'] = average_precision_score(y_true, scores)
    return metrics
```

##### Статистические методы

Статистические методы предполагают, что «нормальные» данные подчиняются некоторому вероятностному распределению (чаще всего нормальному), и ищут наблюдения, которые плохо согласуются с этим распределением.

###### Z-score

Простейший метод — вычислить z-score для каждого признака:

$$z_i = \frac{x_i - \mu}{\sigma}$$

где $\mu$ — среднее, $\sigma$ — стандартное отклонение. Если $|z_i| > t$ (обычно $t = 3$), наблюдение считается аномальным.

Для многомерного случая можно применить этот метод к каждому признаку отдельно и пометить наблюдение как аномалию, если хотя бы один признак выходит за порог.

```python
def zscore_detector(X, threshold=3.0):
    """
    Обнаружение аномалий методом z-score.
    Аномалия, если хотя бы один признак имеет |z| > threshold.
    """
    mean = X.mean(axis=0)
    std = X.std(axis=0)
    z = np.abs((X - mean) / std)
    # Аномалия, если хотя бы один признак выходит за порог
    y_pred = (z > threshold).any(axis=1).astype(int)
    # Оценка аномальности — максимальный z-score по признакам
    scores = z.max(axis=1)
    return y_pred, scores
```

Применим метод к нашим данным:

```python
y_pred_z, scores_z = zscore_detector(X)
metrics_z = evaluate_detector(y, y_pred_z, scores_z)
print("Z-score:", metrics_z)
```

Метод z-score прост, но имеет существенные ограничения:

- Предполагает нормальность распределения.
- Чувствителен к самим аномалиям: при вычислении среднего и стандартного отклонения аномалии «раздувают» $\sigma$, из-за чего порог становится менее чувствительным (эффект маскировки).
- Плохо работает с многомерными данными и коррелированными признаками.

###### Метод межквартильного размаха (IQR)

Более робастный метод — использовать межквартильный размах:

$$\text{IQR} = Q_3 - Q_1, \qquad \text{аномалия, если } x < Q_1 - k \cdot \text{IQR} \text{ или } x > Q_3 + k \cdot \text{IQR}$$

Обычно $k = 1.5$ (умеренные выбросы) или $k = 3$ (сильные выбросы). Этот метод устойчивее к выбросам, чем z-score, так как квартили менее чувствительны к экстремальным значениям.

```python
def iqr_detector(X, k=1.5):
    """
    Обнаружение аномалий методом IQR.
    Аномалия, если хотя бы один признак выходит за границы Q1 - k*IQR, Q3 + k*IQR.
    """
    Q1 = np.percentile(X, 25, axis=0)
    Q3 = np.percentile(X, 75, axis=0)
    IQR = Q3 - Q1
    lower = Q1 - k * IQR
    upper = Q3 + k * IQR
    # Насколько далеко наблюдение выходит за границы (в единицах IQR)
    below = np.maximum(0, (lower - X) / IQR)
    above = np.maximum(0, (X - upper) / IQR)
    deviation = np.maximum(below, above)
    y_pred = (deviation > 0).any(axis=1).astype(int)
    scores = deviation.max(axis=1)
    return y_pred, scores

y_pred_iqr, scores_iqr = iqr_detector(X)
metrics_iqr = evaluate_detector(y, y_pred_iqr, scores_iqr)
print("IQR:", metrics_iqr)
```

###### Расстояние Махаланобиса

Для многомерных данных, учитывающих корреляции между признаками, используют расстояние Махаланобиса:

$$D_M(x) = \sqrt{(x - \mu)^T \Sigma^{-1} (x - \mu)}$$

где $\mu$ — вектор средних, $\Sigma$ — ковариационная матрица. Квадрат расстояния Махаланобиса для нормально распределённых данных подчиняется распределению $\chi^2$ с $p$ степенями свободы (где $p$ — число признаков). Это позволяет задать статистически обоснованный порог.

```python
from scipy.stats import chi2

def mahalanobis_detector(X, confidence=0.975):
    """
    Обнаружение аномалий по расстоянию Махаланобиса.
    Порог определяется по квантилю распределения хи-квадрат.
    """
    mean = X.mean(axis=0)
    cov = np.cov(X.T)
    inv_cov = np.linalg.inv(cov)
    diff = X - mean
    # Квадрат расстояния Махаланобиса
    md2 = np.einsum('ij,jk,ik->i', diff, inv_cov, diff)
    md = np.sqrt(md2)
    # Порог по распределению хи-квадрат
    threshold = chi2.ppf(confidence, df=X.shape[1])
    y_pred = (md2 > threshold).astype(int)
    return y_pred, md

y_pred_md, scores_md = mahalanobis_detector(X)
metrics_md = evaluate_detector(y, y_pred_md, scores_md)
print("Mahalanobis:", metrics_md)
```

##### Методы на основе близости и плотности

Эти методы не делают предположений о распределении данных, а ищут наблюдения, которые находятся далеко от других наблюдений или в областях с низкой плотностью.

###### Local Outlier Factor (LOF)

LOF сравнивает локальную плотность вокруг точки с локальной плотностью вокруг её соседей. Если плотность вокруг точки существенно ниже, чем у соседей, точка считается аномалией.

Ключевая идея: для каждой точки $p$ вычисляется **локальная плотность достижимости** (local reachability density, lrd), а затем LOF-оценка:

$$\text{LOF}_k(p) = \frac{\frac{1}{|N_k(p)|} \sum_{o \in N_k(p)} \text{lrd}_k(o)}{\text{lrd}_k(p)}$$

где $N_k(p)$ — $k$ ближайших соседей точки $p$. Если $\text{LOF}_k(p) \approx 1$, точка типична; если $\text{LOF}_k(p) \gg 1$, точка находится в области с аномально низкой плотностью.

```python
from sklearn.neighbors import LocalOutlierFactor

def lof_detector(X, n_neighbors=20, contamination=0.1):
    """
    Обнаружение аномалий методом LOF.
    
    contamination — ожидаемая доля аномалий в данных.
    """
    lof = LocalOutlierFactor(n_neighbors=n_neighbors,
                             contamination=contamination)
    # predict возвращает -1 для аномалий, 1 для нормы
    y_pred_raw = lof.fit_predict(X)
    y_pred = (y_pred_raw == -1).astype(int)
    # Оценка аномальности: чем больше, тем аномальнее
    scores = -lof.negative_outlier_factor_
    return y_pred, scores

y_pred_lof, scores_lof = lof_detector(X, n_neighbors=20, contamination=0.1)
metrics_lof = evaluate_detector(y, y_pred_lof, scores_lof)
print("LOF:", metrics_lof)
```

Параметр `contamination` задаёт ожидаемую долю аномалий. Если он неизвестен, можно использовать значение по умолчанию (`'auto'`), но тогда порог будет определяться автоматически.

###### DBSCAN

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) — алгоритм кластеризации, который также может использоваться для обнаружения аномалий. Он выделяет кластеры как области с высокой плотностью точек, а точки, не попавшие ни в один кластер, помечает как шум (метка `-1`). Эти точки и считаются аномалиями.

Параметры DBSCAN:

- `eps` — максимальный радиус окрестности;
- `min_samples` — минимальное количество точек в окрестности, чтобы точка считалась «внутренней».

```python
from sklearn.cluster import DBSCAN

def dbscan_detector(X, eps=0.5, min_samples=5):
    """
    Обнаружение аномалий методом DBSCAN.
    Точки с меткой -1 (шум) считаются аномалиями.
    """
    db = DBSCAN(eps=eps, min_samples=min_samples)
    labels = db.fit_predict(X)
    y_pred = (labels == -1).astype(int)
    # Оценка аномальности: расстояние до ближайшего соседа
    from sklearn.neighbors import NearestNeighbors
    nn = NearestNeighbors(n_neighbors=min_samples).fit(X)
    distances, _ = nn.kneighbors(X)
    scores = distances[:, -1]  # расстояние до min_samples-го соседа
    return y_pred, scores

y_pred_db, scores_db = dbscan_detector(X, eps=0.6, min_samples=5)
metrics_db = evaluate_detector(y, y_pred_db, scores_db)
print("DBSCAN:", metrics_db)
```

DBSCAN хорошо работает, когда кластеры имеют примерно одинаковую плотность. Если плотность кластеров сильно различается, DBSCAN может ошибочно помечать точки разреженных кластеров как шум.

##### Методы на основе изоляции

###### Isolation Forest

Isolation Forest — ансамблевый метод, основанный на идее, что аномалии легче «изолировать» от остальных данных. Алгоритм строит множество случайных деревьев решений, в которых на каждом шаге случайно выбирается признак и случайное значение порога. Аномалии, находящиеся далеко от основной массы данных, изолируются за меньшее число шагов (то есть оказываются на меньшей глубине дерева).

Оценка аномальности:

$$s(x, n) = 2^{-\frac{E[h(x)]}{c(n)}}$$

где $E[h(x)]$ — средняя глубина, на которой точка $x$ изолируется в ансамбле деревьев, $c(n)$ — нормировочная константа, зависящая от размера выборки. Чем ближе $s(x, n)$ к 1, тем более аномальной считается точка.

```python
from sklearn.ensemble import IsolationForest

def isolation_forest_detector(X, n_estimators=100, contamination=0.1,
                              random_state=42):
    """
    Обнаружение аномалий методом Isolation Forest.
    """
    iso = IsolationForest(n_estimators=n_estimators,
                          contamination=contamination,
                          random_state=random_state)
    y_pred_raw = iso.fit_predict(X)
    y_pred = (y_pred_raw == -1).astype(int)
    # score_samples: чем меньше, тем аномальнее; инвертируем знак
    scores = -iso.score_samples(X)
    return y_pred, scores

y_pred_if, scores_if = isolation_forest_detector(X, contamination=0.1)
metrics_if = evaluate_detector(y, y_pred_if, scores_if)
print("Isolation Forest:", metrics_if)
```

Isolation Forest — один из самых популярных методов на практике благодаря своей эффективности и устойчивости к размерности. Он не требует предположений о распределении данных и хорошо масштабируется.

##### Методы одноклассовой классификации

Эти методы строят модель только на «нормальных» данных (или на всех данных, но с предположением, что большинство из них — нормальные) и затем определяют, насколько новое наблюдение похоже на нормальное.

###### One-Class SVM

One-Class SVM строит гиперплоскость, которая отделяет «нормальные» данные от начала координат в пространстве признаков (или в пространстве, заданном ядром). Точки, оказавшиеся по «неправильную» сторону гиперплоскости, считаются аномалиями.

Параметр `nu` задаёт верхнюю границу доли аномалий (аналог `contamination`).

```python
from sklearn.svm import OneClassSVM

def one_class_svm_detector(X, kernel='rbf', gamma='scale', nu=0.1):
    """
    Обнаружение аномалий методом One-Class SVM.
    """
    ocsvm = OneClassSVM(kernel=kernel, gamma=gamma, nu=nu)
    ocsvm.fit(X)
    y_pred_raw = ocsvm.predict(X)
    y_pred = (y_pred_raw == -1).astype(int)
    # decision_function: отрицательное для аномалий; инвертируем
    scores = -ocsvm.decision_function(X)
    return y_pred, scores

y_pred_svm, scores_svm = one_class_svm_detector(X, nu=0.1)
metrics_svm = evaluate_detector(y, y_pred_svm, scores_svm)
print("One-Class SVM:", metrics_svm)
```

One-Class SVM хорошо работает на данных небольшой размерности, но чувствителен к выбору параметров `gamma` и `nu`, а также плохо масштабируется на большие выборки (квадратичная сложность).

###### EllipticEnvelope

EllipticEnvelope предполагает, что «нормальные» данные подчиняются многомерному нормальному распределению, и оценивает его параметры (среднее и ковариационную матрицу) робастными методами (Minimum Covariance Determinant). Затем вычисляется расстояние Махаланобиса, и точки, выходящие за порог, считаются аномалиями.

По сути, это робастная версия метода Махаланобиса.

```python
from sklearn.covariance import EllipticEnvelope

def elliptic_envelope_detector(X, contamination=0.1, random_state=42):
    """
    Обнаружение аномалий методом EllipticEnvelope.
    """
    ee = EllipticEnvelope(contamination=contamination,
                          random_state=random_state)
    y_pred_raw = ee.fit_predict(X)
    y_pred = (y_pred_raw == -1).astype(int)
    scores = -ee.decision_function(X)
    return y_pred, scores

y_pred_ee, scores_ee = elliptic_envelope_detector(X, contamination=0.1)
metrics_ee = evaluate_detector(y, y_pred_ee, scores_ee)
print("EllipticEnvelope:", metrics_ee)
```

EllipticEnvelope работает хорошо, когда данные действительно близки к нормальному распределению. Он не подходит для данных сложной формы (например, с несколькими кластерами).

При интерпретации результатов обратите внимание на следующие моменты:

- **Статистические методы** (z-score, IQR) работают независимо по каждому признаку и не учитывают корреляции. Они могут «пропустить» аномалию, которая находится близко к центру по каждому признаку отдельно, но далеко от облака данных по совместному распределению. Кроме того, они чувствительны к форме распределения.
- **Mahalanobis** и **EllipticEnvelope** учитывают корреляции и форму распределения, но предполагают, что нормальные данные имеют эллиптическую форму (близкую к нормальному распределению). На данных сложной формы (например, с несколькими кластерами) они могут давать плохие результаты.
- **LOF** хорошо работает, когда аномалии находятся в областях с низкой плотностью, но может ошибаться, если кластеры имеют разную плотность.
- **DBSCAN** помечает как аномалии все точки, не попавшие в кластеры. Он хорошо работает, когда кластеры имеют примерно одинаковую плотность, но чувствителен к параметрам `eps` и `min_samples`.
- **Isolation Forest** — универсальный метод, который хорошо работает на данных разной формы и размерности. Он не делает сильных предположений о распределении.
- **One-Class SVM** хорошо работает на данных небольшой размерности, но чувствителен к выбору ядра и параметров.

**Практические рекомендации:**

1. Начните с визуализации данных (если размерность позволяет) — это часто даёт больше информации, чем любой автоматический метод.
2. Примените несколько методов и сравните результаты. Если разные методы согласованно указывают на одни и те же точки, это повышает уверенность в том, что они действительно аномальны.
3. Учитывайте предметную область: не каждая статистическая аномалия является ошибкой или мошенничеством. Некоторые аномалии могут быть ценными сигналами (например, новые тенденции).
4. Настройте порог (или `contamination`) в зависимости от задачи. Если пропустить аномалию дороже, чем ложно её обнаружить, снизьте порог (увеличьте `contamination`).

##### Обнаружение аномалий как предварительный анализ данных

Обнаружение аномалий часто используется как этап предварительной обработки данных перед построением моделей машинного обучения. Аномалии могут сильно влиять на параметры моделей (особенно линейных), поэтому их удаление или замена может улучшить качество.

Продемонстрируем это на примере задачи регрессии. Сгенерируем данные с линейной зависимостью и добавим аномалии:

```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

def generate_regression_with_outliers(n_normal=200, n_outliers=20,
                                       random_state=42):
    """
    Генерирует данные для регрессии с аномалиями.
    """
    rng = np.random.RandomState(random_state)
    
    # Нормальные данные: y = 2x + 1 + шум
    X_normal = rng.uniform(0, 10, n_normal)
    y_normal = 2 * X_normal + 1 + rng.randn(n_normal) * 0.5
    
    # Аномалии: те же x, но y сильно отклоняется от линии
    X_out = rng.uniform(0, 10, n_outliers)
    y_out = 2 * X_out + 1 + rng.choice([-1, 1], n_outliers) * \
            rng.uniform(10, 20, n_outliers)
    
    X = np.concatenate([X_normal, X_out]).reshape(-1, 1)
    y = np.concatenate([y_normal, y_out])
    is_anomaly = np.hstack([np.zeros(n_normal), np.ones(n_outliers)]).astype(int)
    
    return X, y, is_anomaly

X_reg, y_reg, is_anomaly_reg = generate_regression_with_outliers()

plt.figure(figsize=(10, 6))
plt.scatter(X_reg[is_anomaly_reg == 0, 0], y_reg[is_anomaly_reg == 0],
            c='tab:blue', s=30, label='Норма', alpha=0.7)
plt.scatter(X_reg[is_anomaly_reg == 1, 0], y_reg[is_anomaly_reg == 1],
            c='tab:red', s=60, marker='x', label='Аномалия')
plt.title('Данные для регрессии с аномалиями')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.grid(True)
plt.show()
```

![Данные с аномалиями](https://github.com/koroteevmv/ML_course/blob/main/ML6.3%20anomalies/img/ml63-8.png?raw=true)

Обучим линейную регрессию на всех данных и на данных без аномалий, сравним качество:

```python
# Разделение на train/test (стратифицируем по наличию аномалий,
# чтобы аномалии попали в обе выборки)
X_train, X_test, y_train, y_test, anom_train, anom_test = train_test_split(
    X_reg, y_reg, is_anomaly_reg,
    test_size=0.3, random_state=42, stratify=is_anomaly_reg
)

# Модель на всех данных
model_all = LinearRegression().fit(X_train, y_train)
y_pred_all = model_all.predict(X_test)
print("Все данные:")
print(f"  R2: {r2_score(y_test, y_pred_all):.4f}")
print(f"  MSE: {mean_squared_error(y_test, y_pred_all):.4f}")

# Модель без аномалий в обучающей выборке
mask_clean = anom_train == 0
model_clean = LinearRegression().fit(X_train[mask_clean], y_train[mask_clean])
y_pred_clean = model_clean.predict(X_test)
print("\nБез аномалий в обучающей выборке:")
print(f"  R2: {r2_score(y_test, y_pred_clean):.4f}")
print(f"  MSE: {mean_squared_error(y_test, y_pred_clean):.4f}")
```

Как правило, удаление аномалий из обучающей выборки значительно улучшает качество модели, особенно если аномалии сильно отклоняются от основной зависимости.
