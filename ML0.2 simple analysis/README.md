#### Методические указания

##### Импорт библиотек и загрузка данных

Начнём с импортов. Это стандартный набор для базового анализа табличных данных.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

plt.rcParams['figure.figsize'] = (10, 5)
pd.set_option('display.max_columns', 30)  # чтобы все столбцы помещались
```

Загружаем обе таблицы:

```python
exam = pd.read_csv('exam_data.csv')
schools = pd.read_csv('schools_info.csv')

print(exam.shape)
print(schools.shape)
```

Должно получиться что-то вроде `(2005, 25)` и `(15, 4)`.

`pd.read_csv` — основной способ чтения табличных данных. Если файл разделён точкой с запятой, укажите `sep=';'`; если используется другая кодировка — `encoding='cp1251'` или `encoding='utf-8'`.

##### Первичное знакомство с данными

Первое, что нужно сделать с новым датафреймом — посмотреть на него. Три главных метода:

```python
exam.head()       # первые 5 строк
exam.tail()       # последние 5 строк
exam.sample(5, random_state=0)  # 5 случайных строк
```

`head` и `tail` удобны для быстрой проверки, что данные прочитались корректно. `sample` полезен, если данные упорядочены (например, по школе или по времени) — тогда `head` покажет только одну часть выборки.

Чтобы понять структуру и типы столбцов, используем `info`:

```python
exam.info()
```

Метод выводит количество строк, названия и типы столбцов и, что важно, **число непустых значений** в каждом. Сразу видно, что в столбцах с заданиями и итоговыми баллами есть пропуски — это и есть «отсутствовавшие».

Быстрая сводная статистика по числовым столбцам:

```python
exam.describe()
```

А по категориальным — с явным указанием, что нужны не числовые:

```python
exam.describe(include='object')
```

Для категориальных `describe` показывает количество уникальных значений (`unique`), самое частое (`top`) и его частоту (`freq`). Полезно, чтобы сразу оценить размер категорий.

> **Совет.** Если столбцов много и `describe` не помещается на экран, выведите статистику только по нужным: `exam[['test_score', 'primary_score']].describe()`.

##### Выбор строк и столбцов, фильтрация

Столбец можно получить двумя способами:

```python
exam['test_score']            # Series
exam[['test_score', 'grade']] # DataFrame (обратите внимание на двойные скобки)
```

Первое — это `Series` (одномерный массив с индексом). Второе — `DataFrame` (двумерная таблица). Разница важна: некоторые методы есть только у `DataFrame`.

Строку можно выбрать по номеру или по метке. Сейчас индекс — это просто номер строки `0, 1, 2, ...`, поэтому `loc` и `iloc` дадут одинаковый результат, но лучше сразу привыкнуть к разнице:

```python
exam.iloc[0]    # по позиции
exam.loc[0]     # по метке индекса
```

Основной инструмент отбора — **булева маска**. Это просто столбец `True`/`False`, который передаётся в `exam[...]`:

```python
exam[exam['gender'] == 'Ж'].head()
exam[exam['test_score'] >= 80].head()
```

Маски можно комбинировать через `&` (и), `|` (или), `~` (не). **Важно:** каждая маска заключается в скобки, потому что приоритет `&` ниже, чем `==`:

```python
exam[(exam['gender'] == 'Ж') & (exam['test_score'] >= 80)].head()
exam[exam['grade'].isin(['4', '5'])].head()
```

`.isin` удобен, когда нужных значений несколько — не писать длинную цепочку `|`.

Чтобы получить сводные цифры по подмножеству, используйте уже знакомые агрегаты прямо на отфильтрованных данных:

```python
# сколько студенток набрали >= 80
len(exam[(exam['gender'] == 'Ж') & (exam['test_score'] >= 80)])

# средний балл по отличникам
exam[exam['grade'] == '5']['test_score'].mean()
```

##### Пропущенные значения и дубликаты

Первое, что надо уметь, — **находить** пропуски:

```python
exam.isna().sum()
```

Метод считает число `NaN` по каждому столбцу. Сразу видно: 20 отсутствовавших дают по 20 пропусков во всех столбцах с заданиями и в итоговых баллах.

Посмотреть сами строки с пропусками:

```python
exam[exam['test_score'].isna()].head()
```

Часто отсутствовавших нужно просто **исключить** из анализа. Основной способ:

```python
exam_clean = exam.dropna(subset=['test_score']).copy()
```

Параметр `subset` ограничивает проверку одним или несколькими столбцами — если, например, в `exam_date` пусто, но `test_score` есть, строку мы не выбрасываем. `.copy()` необязателен, но полезен, чтобы случайно не изменить исходный `exam`.

Заполнение пропусков — тоже вариант, но для итоговых баллов это не имеет смысла (отсутствовавший и правда не имеет балла). Просто запомните базовые методы:

```python
exam['test_score'].fillna(0)                 # конкретным значением
exam['test_score'].fillna(exam['test_score'].mean())  # средним
```

В реальных задачах выбор между удалением и заполнением зависит от смысла признака. Правило простое: **если пропуск означает «значения нет» — удаляем или оставляем как признак; если пропуск — это потеря информации о реальном значении, можно заполнить**.

Теперь **дубликаты**. В выгрузке их несколько:

```python
exam.duplicated().sum()         # сколько полных дубликатов
exam = exam.drop_duplicates()   # удалить их
```

`duplicated()` проверяет все столбцы, `drop_duplicates()` удаляет. Иногда нужно проверить дубликаты только по одному столбцу: `exam.drop_duplicates(subset=['student_id'])`.

> **Замечание.** `drop_duplicates` по умолчанию возвращает новый датафрейм. Чтобы изменить текущий, есть аргумент `inplace=True`, но использовать его не рекомендуется — потом сложно отследить, что переменная изменилась. Лучше всегда переприсваивать: `exam = exam.drop_duplicates()`.

После очистки полезно ещё раз посмотреть размер:

```python
exam_clean = exam.dropna(subset=['test_score']).copy()
print(exam_clean.shape)   # примерно (1980, 25)
```

##### Добавление и преобразование столбцов

Новый столбец добавляется так же, как в словаре — просто присваиванием:

```python
exam['passed'] = (exam['test_score'] >= 40).astype(int)
```

Булево значение превращаем в 0/1 с помощью `.astype(int)`. Это частая операция — многие модели предпочитают числа.

Существующий столбец можно преобразовать. Самый частый случай — **даты**. В нашем датасете `exam_date` — это строка `'2024-06-15'`. Превращаем её в дату:

```python
exam['exam_date'] = pd.to_datetime(exam['exam_date'])
exam['exam_month'] = exam['exam_date'].dt.month
exam['exam_day']   = exam['exam_date'].dt.day
```

После `to_datetime` появляется доступ к аксессору `.dt`, который даёт компоненты даты: месяц, день, день недели, год и т.д. Это резко расширяет возможности анализа.

Ещё один типичный случай — **агрегация по строке**. Сумма по заданиям `B`:

```python
b_cols = [f'B{i}' for i in range(1, 13)]
exam['B_sum'] = exam[b_cols].sum(axis=1)

c_cols = [f'C{i}' for i in range(1, 7)]
exam['C_sum'] = exam[c_cols].sum(axis=1)
```

`axis=1` означает «по строкам» (по горизонтали), `axis=0` — «по столбцам» (по вертикали).

Наконец, если нужно применить одну и ту же функцию к каждому значению столбца, используйте `.map` (для `Series`) или `.apply` (для `Series` и `DataFrame`):

```python
# перекодировать пол в 0/1
exam['gender_code'] = exam['gender'].map({'М': 0, 'Ж': 1})
```

Для замены по словарю `.map` быстрее и понятнее, чем `.apply`.

##### Сортировка

Сортировка нужна, чтобы быстро увидеть «топ» и «хвост»:

```python
exam.sort_values('test_score', ascending=False).head(10)
```

Можно сортировать по нескольким столбцам сразу:

```python
exam.sort_values(['school', 'test_score'],
                 ascending=[True, False]).head(10)
```

Часто после сортировки удобно взять первые или последние `n` строк через `.head(n)` и `.tail(n)`.

##### Группировка и агрегация

`groupby` — рабочая лошадка анализа данных. Он разбивает таблицу на группы по значению одного или нескольких столбцов и позволяет посчитать агрегат по каждой группе.

Простейший пример: средний балл по полу.

```python
exam.groupby('gender')['test_score'].mean()
```

Здесь `exam.groupby('gender')` — это «разбиение на группы», а `['test_score'].mean()` — агрегат.

Несколько агрегатов сразу передаются списком:

```python
exam.groupby('school')['test_score'].agg(['mean', 'median', 'min', 'max', 'count'])
```

Если агрегаты разные для разных столбцов, используется словарь:

```python
exam.groupby('grade').agg({
    'student_id': 'count',
    'test_score': ['mean', 'min', 'max'],
}).head()
```

Сгруппировать можно и по нескольким признакам. Результат получится с **многоуровневым индексом** — его удобно разворачивать в обычную таблицу через `.unstack()`:

```python
exam.groupby(['school', 'gender'])['test_score'].mean().unstack().head()
```

`.unstack()` превращает «внутренний» уровень индекса в столбцы. В нашем случае — по столбцу на каждый пол.

> **Замечание.** У `groupby` есть аргумент `as_index=False` — если указать его, столбец группировки останется обычным столбцом, а не индексом. Иногда это удобнее для последующей работы.

Наконец, `value_counts` — упрощённый аналог `groupby` по одному столбцу:

```python
exam['school'].value_counts().head(10)
exam['grade'].value_counts(normalize=True)   # доли вместо количеств
```

##### Объединение таблиц

Две таблицы (`exam` и `schools`) связаны по столбцу `school`. Чтобы добавить к каждому студенту данные о его школе, используем `merge`:

```python
exam_full = exam.merge(schools, on='school', how='left')
exam_full.head()
```

- `on='school'` — по какому столбцу соединять (он должен называться одинаково в обеих таблицах).
- `how='left'` — **левое соединение**: все строки из левой таблицы (`exam`) сохраняются, а из правой (`schools`) подтягивается то, что нашлось. Если школа в справочнике отсутствует, новые столбцы будут `NaN`.

Другие варианты `how`:

| `how` | Что попадает в результат |
|---|---|
| `'inner'` | только строки, найденные в обеих таблицах |
| `'left'` | все строки левой + совпадения из правой |
| `'right'` | все строки правой + совпадения из левой |
| `'outer'` | все строки из обеих таблиц |

Для добавления строк (например, если у нас есть два файла с одинаковой структурой — за 2023 и 2024 год) используется `pd.concat`:

```python
# допустим, exam_2023 и exam_2024 — два датафрейма с одинаковыми столбцами
combined = pd.concat([exam_2023, exam_2024], ignore_index=True)
```

Разница важна: **`merge` — по горизонтали** (добавляем столбцы), **`concat` — по вертикали** (добавляем строки).

После объединения появляется «грязный» момент: в справочнике часть городов записана строчными буквами (`'москва'` вместо `'Москва'`). Если понадобится считать статистику по городам, названия придётся привести к одному виду:

```python
schools['city'].unique()
schools['city'] = schools['city'].str.title()
schools['city'].unique()
```

`.str` — аксессор для строковых операций. `.title()`, `.lower()`, `.upper()`, `.replace()`, `.contains()` работают как обычные строковые методы, но сразу для всего столбца.

##### Визуализация: связь двух признаков

Чтобы посмотреть, как связаны два числовых признака, используется **диаграмма рассеяния** (`scatterplot`):

```python
sns.scatterplot(data=exam_clean, x='B_sum', y='C_sum',
                hue='gender', alpha=0.5)
plt.title('Сумма баллов за задания B и C')
plt.xlabel('Сумма по B (0–12)')
plt.ylabel('Сумма по C (0–12)')
plt.show()
```

![](https://github.com/koroteevmv/ML_course/blob/2026/ML0.2%20simple%20analysis/img/ml03-6.png?raw=true)

Параметр `hue` добавляет цветовое кодирование по категориальному признаку. `alpha` — прозрачность, помогает при большом числе точек: точки не «забивают» друг друга.

Если один признак числовой, а другой категориальный, диаграмма рассеяния тоже подходит, но `y` (или `x`) будет категориальным. Более информативен в этом случае **ящик с усами** (как в предыдущем разделе) или **скрипичная диаграмма** (`sns.violinplot`) — она показывает и медиану, и форму распределения.

##### Корреляция

Когда нужно быстро оценить **линейную** связь между несколькими числовыми признаками, считают матрицу корреляций:

```python
corr = exam_clean[['B_sum', 'C_sum', 'test_score']].corr()
corr
```

Значения лежат в диапазоне от −1 до 1. Близко к 1 — сильная положительная связь, близко к −1 — сильная отрицательная, около 0 — связи нет.

Наглядно матрицу удобно изображать тепловой картой:

```python
sns.heatmap(corr, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
plt.title('Корреляция признаков')
plt.show()
```

![](https://github.com/koroteevmv/ML_course/blob/2026/ML0.2%20simple%20analysis/img/ml03-7.png?raw=true)

`annot=True` подписывает значения прямо на графике, `cmap` задаёт цветовую схему (хорошо работает `'coolwarm'` — «холодное» для отрицательных, «тёплое» для положительных), `vmin`/`vmax` фиксируют диапазон.

> **Важно понимать.** Корреляция показывает только **линейную** связь. Если точки на диаграмме рассеяния лежат на параболе, коэффициент корреляции может быть близок к 0, хотя связь есть. Поэтому всегда полезно смотреть и на диаграмму рассеяния.
