### Методические указания к контрольной работе №1

#### Цель работы

Проверить, что студент умеет:

- загрузить реальный датасет из OpenML и описать его;
- провести разведочный анализ: распределения, корреляции, масштабы признаков;
- обучить простую и множественную линейную регрессию, посчитать MSE/RMSE/R²;
- разбить данные на train/test и корректно интерпретировать результаты;
- реализовать пакетный градиентный спуск по скелету и сравнить его с `LinearRegression`;
- диагностировать переобучение и недообучение;
- оформить ноутбук с кодом, графиками и содержательными выводами.

#### Соответствие программе

| Задача | Соответствующая тема |
|---|---|
| Загрузка данных, `describe`/`info` | pandas, загрузка данных |
| EDA, гистограммы, корреляции | визуализация, `seaborn` |
| Простая линейная регрессия | `LinearRegression`, парная регрессия |
| Множественная линейная регрессия | множественная регрессия |

Никакие темы из более поздних модулей (классификация, SVM, деревья, ансамбли, кластеризация, кросс-валидация) **не проверяются**.

#### Формат и регламент

| Параметр | Значение |
|---|---|
| Продолжительность | 90 минут (одна пара) |
| Формат сдачи | ноутбук `.ipynb`, сдаётся в конце занятия |
| Куда сдавать | с корпоративной почты студента на корпоративную почту преподавателя |
| Индивидуальность | каждый студент получает свой датасет; два студента одной группы не получают одинаковые |
| Разрешено | официальная документация `sklearn`, `pandas`, `numpy`, `matplotlib`, `seaborn` |
| Запрещено | интернет-поиск, обмен кодом, чат-боты |
| Проверка | запуск ноутбука «Restart & Run All» + ручная проверка по чек-листу |

**Важно.** Если ноутбук не запускается целиком («Restart & Run All»), работа возвращается без проверки.

#### Содержание работы

Работа оформляется как ноутбук. **Каждая задача — минимум одна кодовая ячейка + минимум одна markdown-ячейка с выводом**. Ниже — обязательные задачи с указанием баллов.

##### Задача 1. Загрузка датасета и первичное описание

1. Загрузите датасет по имени через `sklearn.datasets.fetch_openml(name=..., version=1, as_frame=True, parser='auto')`.
2. Выведите: количество строк и столбцов, типы данных (`dtypes`), количество непустых значений в каждом столбце (`info`), основную статистику (`describe`).
3. В markdown-ячейке: напишите, что за задача (регрессия), какая целевая переменная, сколько признаков, есть ли пропуски, какие типы столбцов.

**Что проверяется:** датасет загружен, размеры и типы выведены, описание корректно.

##### Задача 2. Описание предметной области

1. Выведите `data.DESCR` (или его первые 30–40 строк).
2. В markdown-ячейке: перескажите своими словами, **что моделируется** и **зачем** это может быть нужно. Опишите, что означают 2–3 самых важных признака. Если `DESCR` пустой или неинформативный — так и напишите, но опишите, что можно понять из названий столбцов.

**Что проверяется:** описание осмысленное, не скопировано дословно, студент понимает, что моделирует.

##### Задача 3. Очистка данных

1. Удалите нечисловые столбцы, если они есть:
   ```python
   num_cols = X.select_dtypes(include=[np.number]).columns
   X = X[num_cols].copy()
   ```
2. Если в `y` строковый тип — приведите к `float`.
3. Заполните пропуски нулём (`X.fillna(0)`) или медианой — обоснуйте выбор в markdown.
4. В markdown: сколько столбцов удалено, сколько пропусков было, что сделали.

**Что проверяется:** код выполняется, данные стали пригодны для `LinearRegression`.

##### Задача 4. Разведочный анализ

1. Постройте **гистограммы** для первых 12 числовых признаков (сетка 3×4 или 4×3). Подпишите оси и заголовки.
2. Постройте **матрицу корреляций** признаков с целевой переменной (`df.corr()['target'].sort_values()`) и **тепловую карту** (`sns.heatmap`).
3. В markdown: какие признаки сильнее всего связаны с целью, есть ли сильно коррелированные признаки (кандидаты на мультиколлинеарность), есть ли выбросы и асимметричные распределения.

**Что проверяется:** все графики подписаны, тепловая карта читается, выводы соответствуют графикам.

##### Задача 5. Простая линейная регрессия

1. Выберите **один** признак — самый коррелированный с целью (из задачи 4).
2. Обучите `LinearRegression` на этом признаке на **всём** датасете.
3. Выведите `coef_`, `intercept_`, R², RMSE.
4. Постройте scatter: `x` vs `y`, поверх — линия предсказания.
5. В markdown: как интерпретировать коэффициент, насколько хороша модель.

**Что проверяется:** модель обучена, метрики посчитаны, интерпретация корректна.

##### Задача 6. Множественная линейная регрессия

1. Обучите `LinearRegression` на **всех** признаках.
2. Выведите R², RMSE, `coef_` и `intercept_`.
3. Постройте scatter: предсказанные vs реальные значения, добавьте диагональ `y = ŷ`.
4. В markdown: сравните R² с простой моделью. Улучшилась ли модель? Насколько? Какой признак имеет самый большой по модулю коэффициент (после стандартизации — см. подсказку в приложении Б)?

**Что проверяется:** модель обучена на всех признаках, метрики посчитаны, сравнение сделано.

##### Задача 7. Общий вывод по работе

В markdown-ячейке: 5–7 предложений о том, что показал анализ датасета. Что было самым сложным? Какие ограничения у линейной регрессии на этих данных? Какие метрики кажутся наиболее информативными?

**Что проверяется:** осмысленный текст, не «вода», связь с полученными числами.

**Итого по основным задачам:** 80 баллов.

### Структура ноутбука

Работа оформляется по шаблону:

```
Cell 1 (markdown): Заголовок. ФИО, группа, вариант (название датасета), дата.
Cell 2 (code):     Импорты.
Cell 3 (markdown): «Задача 1. Загрузка и описание» — краткое пояснение.
Cell 4 (code):     Загрузка + describe + info.
Cell 5 (markdown): Выводы по задаче 1.
Cell 6 (markdown): «Задача 2. Описание предметной области».
...
Cell N (markdown): «Задача 10. Общий вывод по работе».
```

**Требования к ноутбуку:**

- Все ячейки выполняются сверху вниз без ошибок (проверка «Restart & Run All»).
- Никаких «магических» рестартов, никаких скрытых зависимостей от случайных ячеек.
- Все графики с заголовками и подписями осей.
- Все числа округлены: R² и RMSE — до 3 значащих цифр, коэффициенты — до 3–4 знаков.
- В markdown-ячейках — не «я построил гистограмму», а «распределение X имеет длинный правый хвост, что говорит о выбросах; это может помешать линейной модели».
