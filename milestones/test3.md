#### Данные

Каждый вариант — папка с пятью файлами (структура и генератор — как в КР3):

- `issues_a.csv`, `issues_b.csv`, `issues_c.csv` — обращения клиентов из трёх систем;

- **регрессия** — предсказать числовой `CSAT Score`;
- **классификация** — предсказать `high_csat = 1`, если `CSAT Score >= 4`, иначе `0`.

#### Приложение А. Скелет `batch_gd`

```python
import numpy as np

def batch_gd(X, y, alpha=0.1, n_iters=500):
    n, p = X.shape
    Xb = np.hstack([np.ones((n, 1)), X])   # TODO 1: проверьте
    w = np.zeros(p + 1)                     # TODO 2: проверьте
    losses = []
    for _ in range(n_iters):
        pred = Xb @ w                       # TODO 3
        grad = Xb.T @ (pred - y) / n        # TODO 4
        w = w - alpha * grad                # TODO 5
        losses.append(np.mean((pred - y) ** 2))  # TODO 6
    return w, losses
```
