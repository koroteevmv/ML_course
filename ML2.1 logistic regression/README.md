Скрипт ниже генерирует данные и сохраняет их в `logreg_data.csv`. Датасет — два класса, две признака, линейно разделимые с некоторым перекрытием.

```python
# prepare_data.py
import numpy as np
import pandas as pd


def generate_data(n=500, random_state=42, path='logreg_data.csv'):
    """Два гауссовых облака с перекрытием."""
    rng = np.random.RandomState(random_state)
    n_per_class = n // 2

    # Класс 0: центр (-1, -1)
    X0 = rng.randn(n_per_class, 2) * 0.8 + np.array([-1.0, -1.0])
    # Класс 1: центр (1, 1)
    X1 = rng.randn(n_per_class, 2) * 0.8 + np.array([1.0, 1.0])

    X = np.vstack([X0, X1])
    y = np.hstack([np.zeros(n_per_class), np.ones(n_per_class)])

    # Перемешаем
    idx = rng.permutation(n)
    df = pd.DataFrame({'x1': X[idx, 0], 'x2': X[idx, 1], 'y': y[idx].astype(int)})
    df.to_csv(path, index=False)
    print(f'{path}: {df.shape}, классы: {df.y.value_counts().to_dict()}')
    return df


if __name__ == '__main__':
    generate_data()
```

#### Методические указания

##### От линейной регрессии к классификации

В линейной регрессии мы предсказывали **число**:

$$\hat{y} = w_0 + w_1 x_1 + w_2 x_2 = w^T x$$

Для классификации это не подходит: $\hat{y}$ может быть любым числом от $-\infty$ до $+\infty$, а нам нужна **вероятность** класса 1 — число от 0 до 1. Если просто «обрезать» линейный выход по нулю и единице (ступенчатая функция), получится плохо: функция разрывна, и градиентный спуск не работает (производная везде ноль или не определена).

Решение — **сигмоида** (логистическая функция):

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Она превращает любое вещественное число в число от 0 до 1, при этом гладкая и монотонная. Применяем её к линейному выходу:

$$\hat{p} = \sigma(w^T x) = \frac{1}{1 + e^{-w^T x}}$$

Теперь $\hat{p}$ можно интерпретировать как **вероятность** того, что объект принадлежит классу 1.

Построим сигмоиду:

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

z = np.linspace(-10, 10, 400)
plt.figure(figsize=(10, 5))
plt.plot(z, sigmoid(z), linewidth=2)
plt.axhline(0.5, color='gray', linestyle='--', label='Порог 0.5')
plt.axvline(0, color='gray', linestyle='--')
plt.xlabel('z = w^T x')
plt.ylabel('σ(z)')
plt.title('Сигмоида: превращает любое число в вероятность')
plt.legend()
plt.grid(True)
plt.show()
```

**Свойства сигмоиды:**

- $\sigma(0) = 0.5$ — «нейтральное» предсказание.
- $\sigma(z) \to 1$ при $z \to +\infty$, $\sigma(z) \to 0$ при $z \to -\infty$.
- Производная $\sigma'(z) = \sigma(z) \cdot (1 - \sigma(z))$ — ключевое свойство, которое сделает градиентный спуск простым.

**Как принимать решение?** Обычно порог 0.5: если $\hat{p} \geq 0.5$ — класс 1, иначе класс 0. Порог можно менять — этому посвящена отдельная лабораторная про ROC-кривые.

##### Вероятностная интерпретация

Логистическую регрессию можно вывести из **вероятностной модели**. Предположим, что:

- $P(y = 1 \mid x) = \sigma(w^T x)$,
- $P(y = 0 \mid x) = 1 - \sigma(w^T x)$.

Оба выражения можно объединить в одну формулу:

$$P(y \mid x) = \sigma(w^T x)^y \cdot (1 - \sigma(w^T x))^{1-y}$$

Проверим: при $y = 1$ остаётся $\sigma(w^T x)$, при $y = 0$ — $(1 - \sigma(w^T x))$. Работает.

Теперь задача — найти такие $w$, при которых **вероятность увидеть именно наши данные** максимальна. Это принцип **максимального правдоподобия** (maximum likelihood). Он естественно приводит к функции ошибки, которую мы сейчас выведем.

##### Функция ошибки: от правдоподобия к кросс-энтропии

Для $n$ независимых наблюдений правдоподобие:

$$L(w) = \prod_{i=1}^n P(y_i \mid x_i) = \prod_{i=1}^n \sigma_i^{y_i} (1 - \sigma_i)^{1 - y_i}$$

где $\sigma_i = \sigma(w^T x_i)$. Произведение — численно неудобно (переполнение/обнуление). Возьмём логарифм — он монотонен, максимум не сдвинется:

$$\ell(w) = \log L(w) = \sum_{i=1}^n \left[ y_i \log \sigma_i + (1 - y_i) \log (1 - \sigma_i) \right]$$

Задача — **максимизировать** $\ell(w)$. В машинном обучении принято **минимизировать** функцию ошибки, поэтому возьмём со знаком минус и усредним по $n$:

$$J(w) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log \sigma_i + (1 - y_i) \log (1 - \sigma_i) \right]$$

Это и есть **бинарная кросс-энтропия** (binary cross-entropy, BCE, log-loss). Именно её использует логистическая регрессия.

**Как понимать эту формулу интуитивно?** Для каждого объекта только один член суммы ненулевой:

- Если истинный класс $y_i = 1$: вклад $= -\log \sigma_i$. Чем больше $\sigma_i$ (модель уверена в классе 1), тем меньше вклад. Если $\sigma_i \to 1$, вклад $\to 0$; если $\sigma_i \to 0$ (модель сильно ошибается), вклад $\to +\infty$.
- Если $y_i = 0$: вклад $= -\log(1 - \sigma_i)$. Аналогично, модель штрафуется за высокую $\sigma_i$.

То есть **функция ошибки сильно штрафует уверенные неправильные ответы** и слабо — неуверенные. Это ключевое свойство: MSE так себя не ведёт.

**Почему не MSE?** Если использовать $J = \frac{1}{n}\sum(\sigma_i - y_i)^2$, то:

- Функция становится **невыпуклой** — градиентный спуск может застрять в локальном минимуме.
- Градиент содержит множитель $\sigma'(z)$, который при больших $|z|$ близок к нулю — обучение «замедляется» в самых проблемных местах.

Кросс-энтропия этих проблем лишена.

**Визуализируем потери.** Построим график $-\log(p)$ и $-\log(1-p)$ — цены за уверенность:

```python
p = np.linspace(0.001, 0.999, 500)
plt.figure(figsize=(10, 5))
plt.plot(p, -np.log(p), label='−log(p) — потеря при y=1', linewidth=2)
plt.plot(p, -np.log(1 - p), label='−log(1−p) — потеря при y=0', linewidth=2)
plt.xlabel('Предсказанная вероятность p')

```

Видно, что при уверенной ошибке ($p \to 0$ при $y=1$ или $p \to 1$ при $y=0$) потеря уходит в бесконечность. Модель не может «отсидеться» с неправильным предсказанием.

##### Связь с информационной энтропией

Кросс-энтропия — не случайное название. Она напрямую связана с **информационной энтропией** Шеннона.

**Энтропия** распределения $p$:

$$H(p) = -\sum_{k} p_k \log p_k$$

Это мера «неопределённости»: для бинарного случая $H(p) = -p \log p - (1-p) \log(1-p)$. Максимум при $p = 0.5$ (полная неопределённость, $H = \log 2$), минимум при $p = 0$ или $p = 1$ (полная уверенность, $H = 0$).

**Кросс-энтропия** между истинным распределением $y$ и предсказанным $\hat{p}$:

$$H(y, \hat{p}) = -\sum_k y_k \log \hat{p}_k$$

Для бинарного случая:

$$H(y, \hat{p}) = -\left[ y \log \hat{p} + (1-y) \log(1 - \hat{p}) \right]$$

Это ровно то, что мы получили из правдоподобия. То есть **минимизация логистической функции ошибки — это минимизация кросс-энтропии между истинными метками и предсказанными вероятностями**.

**Что это даёт на практике?**

1. **Интерпретация:** кросс-энтропия измеряет, сколько «лишней информации» модель тратит на описание данных из-за своей неправильности. Идеальная модель имеет $H(y, \hat{p}) = 0$.
2. **Связь с KL-дивергенцией:** $H(y, \hat{p}) = H(y) + D_{KL}(y \| \hat{p})$. Поскольку $H(y)$ — константа (зависит только от данных), минимизация кросс-энтропии эквивалентна минимизации **KL-дивергенции** — «расстояния» между распределениями. Это формальное обоснование, почему кросс-энтропия — «правильная» функция ошибки.
3. **Единый взгляд на ML:** та же кросс-энтропия используется в softmax-регрессии (многоклассовая), в нейросетях для классификации, в языковых моделях. Понимание этой связи полезно далеко за пределами логистической регрессии.

**Небольшая проверка.** Сравним значения MSE и кросс-энтропии для одного объекта при разных уровнях уверенности:

```python
def bce_loss(p, y):
    p = np.clip(p, 1e-15, 1 - 1e-15)  # защита от log(0)
    return -(y * np.log(p) + (1 - y) * np.log(1 - p))

def mse_loss(p, y):
    return (p - y) ** 2

print(f'{"p":>6} {"y":>3} {"BCE":>10} {"MSE":>10}')
for p in [0.01, 0.1, 0.4, 0.5, 0.6, 0.9, 0.99]:
    for y in [0, 1]:
        print(f'{p:>6.2f} {y:>3} {bce_loss(p, y):>10.4f} {mse_loss(p, y):>10.4f}')
```

Обратите внимание: при уверенной ошибке ($p=0.01, y=1$) BCE ≈ 4.6, а MSE всего ≈ 0.98. Кросс-энтропия штрафует в 5 раз сильнее — это то самое «дорого стоит».

##### Градиент функции ошибки

Чтобы минимизировать $J(w)$ градиентным спуском, нужен её градиент. Считаем производную по $w_j$:

$$\frac{\partial J}{\partial w_j} = \frac{1}{n} \sum_{i=1}^n (\sigma_i - y_i) \cdot x_{ij}$$

В матричной форме:

$$\nabla J(w) = \frac{1}{n} X^T (\sigma(X w) - y)$$

Поразительно простая формула — и это не случайность. Градиент кросс-энтропии от сигмоиды «съедает» производную сигмоиды, оставляя только разность «предсказание минус истина». В этом и сила кросс-энтропии: она даёт **большой градиент при больших ошибках** и маленький при маленьких. Именно то, что нужно для быстрого обучения.

##### Реализация модели руками

Соберём всё вместе в класс с интерфейсом, близким к `sklearn` (методы `fit` и `predict`, атрибуты `coef_`, `intercept_`).

```python
class LogisticRegressionManual:
    def __init__(self, alpha=0.1, n_iters=1000):
        self.alpha = alpha
        self.n_iters = n_iters

    def _sigmoid(self, z):
        return 1 / (1 + np.exp(-z))

    def fit(self, X, y):
        n, p = X.shape
        # Добавим столбец единиц для intercept
        X_design = np.hstack([np.ones((n, 1)), X])
        w = np.zeros(p + 1)

        self.loss_history_ = []
        for _ in range(self.n_iters):
            z = X_design @ w
            sigma = self._sigmoid(z)
            # Градиент кросс-энтропии
            grad = X_design.T @ (sigma - y) / n
            w -= self.alpha * grad
            # Сохраним значение функции ошибки
            loss = -np.mean(y * np.log(sigma + 1e-15) +
                            (1 - y) * np.log(1 - sigma + 1e-15))
            self.loss_history_.append(loss)

        self.intercept_ = w[0]
        self.coef_ = w[1:]
        return self

    def predict_proba(self, X):
        z = self.intercept_ + X @ self.coef_
        return self._sigmoid(z)

    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)
```

##### Визуализация границы принятия решений

Граница принятия решений — это линия уровня $\sigma(z) = 0.5$, то есть $z = w^T x = 0$:

$$w_0 + w_1 x_1 + w_2 x_2 = 0 \;\Longrightarrow\; x_2 = -\frac{w_0 + w_1 x_1}{w_2}$$

Построим её на графике с точками:

```python
plt.figure(figsize=(8, 6))
plt.scatter(X_tr[y_tr == 0, 0], X_tr[y_tr == 0, 1],
            c='tab:blue', s=30, alpha=0.6, label='Класс 0')
plt.scatter(X_tr[y_tr == 1, 0], X_tr[y_tr == 1, 1],
            c='tab:red', s=30, alpha=0.6, marker='x', label='Класс 1')

x1_line = np.linspace(X[:, 0].min(), X[:, 0].max(), 100)
w0 = model_sklearn.intercept_[0]
w1, w2 = model_sklearn.coef_[0]
x2_line = -(w0 + w1 * x1_line) / w2

plt.plot(x1_line, x2_line, 'k-', linewidth=2, label='Граница решения')
plt.xlabel('x1')
plt.ylabel('x2')
plt.title('Логистическая регрессия: линейная граница решения')
plt.legend()
plt.grid(True)
plt.axis('equal')
plt.show()
```

**Важно понять:** логистическая регрессия всегда строит **линейную** границу решения (прямую в 2D, гиперплоскость в многомерном пространстве). Её главное преимущество — вероятность, а не форма границы. Если нужна нелинейная граница, добавляют полиномиальные признаки (как в лабораторной про множественную регрессию) или используют другие модели (SVM, деревья — в следующих лабораторных).

##### Базовые метрики классификации

`accuracy` — простая и понятная метрика, но у неё есть ограничения. Для полноты картины посчитаем ещё несколько:

```python
from sklearn.metrics import (accuracy_score, precision_score,
                              recall_score, f1_score, confusion_matrix)

print(f'Accuracy:  {accuracy_score(y_te, y_pred_sklearn):.4f}')
print(f'Precision: {precision_score(y_te, y_pred_sklearn):.4f}')
print(f'Recall:    {recall_score(y_te, y_pred_sklearn):.4f}')
print(f'F1:        {f1_score(y_te, y_pred_sklearn):.4f}')
print('\nМатрица ошибок:')
print(confusion_matrix(y_te, y_pred_sklearn))
```

**Кратко:** precision — какая доля предсказанных «1» действительно «1»; recall — какую долю истинных «1» мы нашли; F1 — их гармоническое среднее. Подробнее — в лабораторной про метрики и ROC-кривые.
