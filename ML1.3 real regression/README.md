#### Подготовка данных

Работаем с классическим реальным датасетом **California Housing** — это данные о ценах на недвижимость в Калифорнии по результатам переписи 1990 года. Датасет встроен в `sklearn`, скачивается один раз (~1 МБ), дальнейшие запуски работают из кэша.

**Признаки** (8 числовых):

- `MedInc` — медианный доход домохозяйства в районе (в десятках тысяч долларов);
- `HouseAge` — медианный возраст домов в районе;
- `AveRooms` — среднее число комнат на домохозяйство;
- `AveBedrms` — среднее число спален на домохозяйство;
- `Population` — население района;
- `AveOccup` — среднее число жителей на домохозяйство;
- `Latitude`, `Longitude` — координаты района.

**Целевая переменная**: `MedHouseVal` — медианная стоимость дома в районе (в сотнях тысяч долларов). Значения **ограничены сверху** примерно на 5.0 (это медианная цена, зафиксированная переписью; районы с более дорогими домами «прижаты» к этому потолку).

> **Важно помнить про ограничение целевой переменной.** Оно часто встречается в реальных данных (страховые выплаты, зарплаты, оценки) и создаёт проблемы при моделировании. Обсудим это в разделе про остатки.

#### Методические указания

##### Простая линейная регрессия как baseline

Всегда начинайте с самой простой модели. Парная регрессия на одном признаке (`MedInc`) — это baseline, с которым потом сравнивают всё остальное.

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Парная регрессия: MedInc → MedHouseVal
lr_simple = LinearRegression().fit(X_tr[['MedInc']], y_tr)
y_pred_simple = lr_simple.predict(X_te[['MedInc']])

print(f'R² = {r2_score(y_te, y_pred_simple):.3f}')
print(f'RMSE = {np.sqrt(mean_squared_error(y_te, y_pred_simple)):.3f}')
print(f'Коэффициент: {lr_simple.coef_[0]:.3f}')
print(f'Свободный член: {lr_simple.intercept_:.3f}')
```

Типичный $R^2$ — около 0.47. Это скромно: одна `MedInc` объясняет лишь около половины разброса цен. Визуально проверим:

```python
plt.figure(figsize=(10, 5))
plt.scatter(X_te['MedInc'], y_te, s=8, alpha=0.3, label='Данные')

plt.plot(X_grid, lr_simple.predict(pd.DataFrame({'MedInc': X_grid})),
         'r-', linewidth=2, label='Предсказание модели')

plt.ylabel('MedHouseVal (стоимость, $100k)')

plt.show()
```

На графике видно две проблемы:

- Точки **сильно разбросаны** — одна `MedInc` не может объяснить цену.
- **Горизонтальная «полоса» у 5.0** — та самая отсечка. Модель не может её «увидеть», а данные в этой области не описываются линейной зависимостью.

##### Множественная линейная регрессия

Добавим все признаки. Модель та же, но признаков теперь 8:

```python
lr_full = LinearRegression().fit(X_tr, y_tr)
y_pred_full = lr_full.predict(X_te)

print(f'R² = {r2_score(y_te, y_pred_full):.3f}')
print(f'RMSE = {np.sqrt(mean_squared_error(y_te, y_pred_full)):.3f}')
print()
print('Коэффициенты:')
for name, coef in zip(X.columns, lr_full.coef_):
    print(f'  {name}: {coef:+.4f}')
print(f'Intercept: {lr_full.intercept_:+.4f}')
```

Типичный $R^2$ — около 0.60. Улучшение по сравнению с baseline заметное, но не радикальное. Причина — **сложность зависимости**: цена на жильё определяется не только линейной комбинацией признаков, но и их взаимодействиями, географией и нелинейностями.

**Как читать коэффициенты.** Коэффициент $\beta_j$ — это изменение целевой переменной при увеличении признака $x_j$ **на единицу при фиксированных остальных признаках**.

- `MedInc: +0.44` — при росте медианного дохода района на 1 (то есть на $10k) медианная стоимость дома растёт на $0.44 \times 100k = $44k. Логично.
- `HouseAge: +0.009` — практически ноль. Возраст дома сам по себе почти не влияет на цену.
- `AveRooms: -0.11` — **отрицательный** коэффициент. Это может показаться странным (больше комнат — дешевле?), но это эффект **мультиколлинеарности**: `AveRooms` и `AveBedrms` сильно коррелированы, и коэффициенты «делят» между собой эффект.
- `Latitude: -0.42` — интерпретировать сложно: это «поправка» на координату при фиксированной `Longitude` и остальных признаках. Смысл в том, что **сочетание** координат кодирует местоположение.

> **Практический вывод.** Интерпретировать коэффициенты можно, но с оговорками: при сильной корреляции признаков коэффициенты нестабильны, а их знак может не соответствовать интуиции. Это одна из причин, по которой используют регуляризацию (см. раздел 5).

##### Анализ остатков и статистическая достоверность

Простая модель с $R^2 = 0.60$ — это хорошо, но насколько ей можно верить? Три простых инструмента:

###### Нормальность остатков

Для линейной регрессии важно, чтобы остатки были примерно нормально распределены — тогда работают доверительные интервалы и тесты значимости коэффициентов.

```python
fig, axes = plt.subplots(1, 2, figsize=(14, 4))

sns.histplot(residuals, bins=60, kde=True, ax=axes[0])
axes[0].set_title('Распределение остатков')
axes[0].set_xlabel('Остаток')

from scipy import stats
stats.probplot(residuals, dist='norm', plot=axes[1])
axes[1].set_title('Q-Q plot остатков')
plt.tight_layout(); plt.show()

# Тест Шапиро-Уилка (на подвыборке, т.к. на 5000+ точках он почти всегда отвергает гипотезу)
sample = np.random.RandomState(0).choice(residuals, 1000, replace=False)
stat, p = stats.shapiro(sample)
print(f'Shapiro-Wilk: W = {stat:.4f}, p-value = {p:.4e}')
print(f'Среднее остатков: {residuals.mean():.4f}')
print(f'Ст. отклонение:   {residuals.std():.4f}')
```

Типичная картина: остатки **не нормальны** (p-value крошечное), есть правый хвост. Это не «провал» модели, а отражение реальных данных — цена на жильё имеет тяжёлый правый хвост и отсечку сверху. Для интерпретации метрик это не критично, но для доверительных интервалов — важно.

###### Доверительный интервал для $R^2$ (bootstrap)

Одна цифра $R^2 = 0.60$ не говорит о стабильности. Bootstrap даёт представление о разбросе:

```python
def bootstrap_r2(X_tr, y_tr, X_te, y_te, n_bootstrap=300, seed=0):
    rng = np.random.RandomState(seed)
    r2s = []
    n = len(X_tr)
    for _ in range(n_bootstrap):
        idx = rng.choice(n, size=n, replace=True)
        # Восстановим DataFrame, чтобы сохранить имена столбцов
        Xb = X_tr.iloc[idx]
        yb = y_tr.iloc[idx]
        model = LinearRegression().fit(Xb, yb)
        r2s.append(r2_score(y_te, model.predict(X_te)))
    return np.array(r2s)

r2_boots = bootstrap_r2(X_tr, y_tr, X_te, y_te)
print(f'R² = {r2_score(y_te, y_pred_full):.3f}')
print(f'95% CI: [{np.percentile(r2_boots, 2.5):.3f}, '
      f'{np.percentile(r2_boots, 97.5):.3f}]')

plt.figure(figsize=(8, 4))
sns.histplot(r2_boots, bins=40, kde=True)
plt.axvline(r2_score(y_te, y_pred_full), color='r', linestyle='--',
            label='Точечная оценка')
plt.axvline(np.percentile(r2_boots, 2.5), color='gray', linestyle=':')
plt.axvline(np.percentile(r2_boots, 97.5), color='gray', linestyle=':',
            label='95% CI')
plt.title('Bootstrap-распределение R²')
plt.legend()
plt.show()
```

Типичный результат: $R^2 = 0.60$, 95% CI примерно $[0.58, 0.62]$. Разброс небольшой — оценка стабильная. Если бы разброс был шире (например, $[0.45, 0.75]$), стоило бы задуматься о надёжности модели.

###### Доверительный интервал для предсказания

Для отдельного района мы можем дать не только точечный прогноз, но и интервал:

```python
# Возьмём 5 случайных объектов из test и построим для них CI
sample_idx = np.random.RandomState(0).choice(len(X_te), 5, replace=False)
X_sample = X_te.iloc[sample_idx]
y_sample_true = y_te.iloc[sample_idx].values

# Bootstrap предсказаний
preds_boot = []
for _ in range(300):
    # Bootstrap по train
    idx = np.random.RandomState(len(preds_boot)).choice(len(X_tr), len(X_tr))
    model = LinearRegression().fit(X_tr.iloc[idx], y_tr.iloc[idx])
    preds_boot.append(model.predict(X_sample))
preds_boot = np.array(preds_boot)  # (n_bootstrap, n_samples)

lower = np.percentile(preds_boot, 2.5, axis=0)
upper = np.percentile(preds_boot, 97.5, axis=0)
mean_pred = preds_boot.mean(axis=0)

print(f'{"№":>3} {"Истина":>8} {"ŷ":>8} {"95% CI":>20}')
for i in range(5):
    print(f'{i:>3} {y_sample_true[i]:>8.3f} {mean_pred[i]:>8.3f} '
          f'[{lower[i]:>6.3f}, {upper[i]:>6.3f}]')
```

Такой bootstrap-интервал — практичный и понятный заказчику. Обратите внимание, что в интервал попадает большинство истинных значений, но не все — это нормально, интервал 95%.

> **Замечание.** Более точный (аналитический) интервал для предсказания вычисляется по формуле $\hat{y} \pm t_{\alpha/2, n-p-1} \cdot s \cdot \sqrt{1 + x^T(X^TX)^{-1}x}$. Здесь мы используем bootstrap, потому что он проще и не требует ручных выкладок. Для учебных целей его достаточно.

##### Регуляризованные модели

В множественной регрессии с реальными данными часто возникает **мультиколлинеарность** (признаки коррелированы) и **переобучение** (если признаков много). Регуляризация решает обе проблемы, добавляя штраф за большие коэффициенты.

**Ridge (L2-регуляризация).** Штраф $\lambda \sum \beta_j^2$. «Сжимает» все коэффициенты к нулю, но не обнуляет их полностью. Хорошо работает при мультиколлинеарности.

**Lasso (L1-регуляризация).** Штраф $\lambda \sum |\beta_j|$. Заставляет часть коэффициентов **точно** обращаться в ноль — это встроенный **отбор признаков**.

**ElasticNet.** Комбинация L1 и L2 — компромисс между Ridge и Lasso.

```python
from sklearn.linear_model import Ridge, Lasso, ElasticNet

# Стандартизация: регуляризация чувствительна к масштабу!
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler().fit(X_tr)
X_tr_sc = scaler.transform(X_tr)
X_te_sc = scaler.transform(X_te)

models = {
    'LinearRegression': LinearRegression(),
    'Ridge (α=1)': Ridge(alpha=1.0),
    'Lasso (α=0.01)': Lasso(alpha=0.01, max_iter=10000),
    'ElasticNet (α=0.01)': ElasticNet(alpha=0.01, l1_ratio=0.5, max_iter=10000),
}

print(f'{"Модель":<25} {"R² (train)":>12} {"R² (test)":>12} {"Ненулевых":>12}')
print('-' * 65)
for name, model in models.items():
    if name == 'LinearRegression':
        model.fit(X_tr, y_tr)
        r2_tr = model.score(X_tr, y_tr)
        r2_te = model.score(X_te, y_te)
        n_nonzero = np.sum(np.abs(model.coef_) > 1e-6)
    else:
        model.fit(X_tr_sc, y_tr)
        r2_tr = model.score(X_tr_sc, y_tr)
        r2_te = model.score(X_te_sc, y_te)
        n_nonzero = np.sum(np.abs(model.coef_) > 1e-6)
    print(f'{name:<25} {r2_tr:>12.4f} {r2_te:>12.4f} {n_nonzero:>12d}')
```

**Что обычно видно:**

- **Ridge** даёт примерно такой же $R^2$, как обычная линейная регрессия. Если мультиколлинеарность сильная, может быть немного лучше — коэффициенты стабильнее.
- **Lasso** при достаточном $\alpha$ обнуляет часть коэффициентов. Например, `HouseAge` или `AveBedrms` могут «выпасть» из модели — сигнал, что они не добавляют информации.
- **Ridge/Lasso требуют стандартизации.** Иначе штраф будет «несправедливо» сильнее наказывать признаки с большим масштабом.

**Влияние $\alpha$** (силы регуляризации) на качество:

```python
alphas = np.logspace(-3, 3, 20)

ridge_scores = []
lasso_scores = []
for a in alphas:
    r = Ridge(alpha=a).fit(X_tr_sc, y_tr)
    ridge_scores.append(r.score(X_te_sc, y_te))
    l = Lasso(alpha=a, max_iter=10000).fit(X_tr_sc, y_tr)
    lasso_scores.append(l.score(X_te_sc, y_te))

plt.figure(figsize=(10, 5))
plt.semilogx(alphas, ridge_scores, 'o-', label='Ridge')
plt.semilogx(alphas, lasso_scores, 's-', label='Lasso')
plt.xlabel('α (сила регуляризации)')
plt.ylabel('R² на test')
plt.title('Влияние α на качество модели')
plt.legend()
plt.grid(True)
plt.show()
```

Типичная картина:

- **Ridge:** $R^2$ почти не меняется в широком диапазоне $\alpha$, а при очень больших $\alpha$ — падает (модель становится слишком «простой»).
- **Lasso:** $R^2$ максимален при некотором среднем $\alpha$ (когда модель отбирает полезные признаки), а при больших $\alpha$ — тоже падает (модель «выкидывает» слишком много).

Оптимальное $\alpha$ находят через кросс-валидацию (см. лабораторную про кросс-валидацию):

```python
from sklearn.linear_model import RidgeCV, LassoCV

ridge_cv = RidgeCV(alphas=np.logspace(-3, 3, 20), cv=5).fit(X_tr_sc, y_tr)
print(f'Оптимальный α для Ridge: {ridge_cv.alpha_:.4f}')
print(f'R² на test: {ridge_cv.score(X_te_sc, y_te):.4f}')
```
